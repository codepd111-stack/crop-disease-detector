# 🌿 Crop Disease Detector

I built this because farmers often can't tell what's wrong with their crops until it's too late. This tool lets anyone take a photo of a leaf and find out what disease it has — along with what to actually do about it.

## What it does

Upload a photo of a plant leaf (from your phone or desktop), and the app will:

- Identify the disease from 38 possible conditions across 14 crop types
- Show you how confident it is, along with alternative possibilities
- Give you a plain-English treatment recommendation generated by an AI

## How it works

A fine-tuned EfficientNet-B0 model handles the visual classification. I trained it on the PlantVillage dataset and put extra effort into making it work on real-world photos — not just clean lab images. The treatment advice comes from a Groq-hosted LLM orchestrated through LangChain.

The backend is a FastAPI server and the frontend is React. The whole thing runs locally with two commands.

## Tech Stack

- **Model** — EfficientNet-B0 fine-tuned with PyTorch
- **Backend** — FastAPI
- **LLM** — LangChain + Groq (llama-3.3-70b-versatile)
- **Frontend** — React + Vite

## Running it locally

You'll need Python 3.10+, Node.js, and a free Groq API key from console.groq.com.

**Backend**

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```

**Frontend**

```bash
cd frontend
npm install
npm run dev
```

Then open `http://localhost:5173` and upload any leaf photo.
